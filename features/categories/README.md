# features/categories

Lógica de dominio para la gestión de categorías de transacciones.

## Contenido previsto

- `actions.ts` — Server Actions para crear, editar y eliminar categorías
- `queries.ts` — consultas de categorías del usuario
- `schemas.ts` — esquemas de validación
- `types.ts` — tipos del dominio (Category, CategoryType, etc.)
