# features/goals

Lógica de dominio para el seguimiento de metas de ahorro.

## Contenido previsto

- `actions.ts` — Server Actions para crear y actualizar metas
- `queries.ts` — consultas de progreso y estado de metas
- `schemas.ts` — esquemas de validación
- `types.ts` — tipos del dominio (Goal, GoalStatus, etc.)
