# features/reminders

Lógica de dominio para recordatorios de pagos y fechas importantes.

## Contenido previsto

- `actions.ts` — Server Actions para crear, editar y eliminar recordatorios
- `queries.ts` — consultas de recordatorios próximos y vencidos
- `schemas.ts` — esquemas de validación
- `types.ts` — tipos del dominio (Reminder, ReminderFrequency, etc.)
