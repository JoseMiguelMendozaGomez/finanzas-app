# features/auth

Lógica de dominio relacionada con la autenticación y gestión de sesión.

## Contenido previsto

- `actions.ts` — Server Actions para login, registro y logout
- `schemas.ts` — esquemas de validación con Zod
- `types.ts` — tipos TypeScript del dominio (User, Session, etc.)
- `queries.ts` — consultas a base de datos relacionadas con usuarios
