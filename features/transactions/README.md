# features/transactions

Lógica de dominio para el registro y consulta de transacciones financieras.

## Contenido previsto

- `actions.ts` — Server Actions para crear, editar y eliminar transacciones
- `queries.ts` — consultas con filtros, paginación y ordenamiento
- `schemas.ts` — esquemas de validación
- `types.ts` — tipos del dominio (Transaction, TransactionType, etc.)
