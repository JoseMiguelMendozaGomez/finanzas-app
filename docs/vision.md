# Inverza

## Objetivo

Aplicación web para gestión de finanzas personales.

## MVP

- Registro de ingresos
- Registro de gastos
- Categorías
- Metas de ahorro
- Recordatorios de pago
- Dashboard financiero

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- Auth.js

## Arquitectura

Monolito modular organizado por features.

## Futuro

- Presupuestos
- Multiusuario
- Reportes
- Aplicación móvil
