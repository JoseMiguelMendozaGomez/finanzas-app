# lib/utils

Funciones utilitarias generales sin dependencia de dominio.

## Contenido previsto

- `currency.ts` — formateo y conversión de moneda
- `date.ts` — helpers de fechas (formateo, rangos, comparaciones)
- `cn.ts` — utilidad para combinar clases de Tailwind (`clsx` + `tailwind-merge`)
- `validators.ts` — validaciones genéricas reutilizables
